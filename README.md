# Huxulm's Scoop Bucket

Personal [Scoop](https://scoop.sh) bucket for CLI tools by Huxulm.

## Usage

```powershell
scoop bucket add huxulm https://github.com/huxulm/scoop-bucket
scoop install lcctl
```

## Packages

- **lcctl**: LeetCode China (`leetcode.cn`) CLI and interactive terminal assistant ([huxulm/lcctl](https://github.com/huxulm/lcctl))
